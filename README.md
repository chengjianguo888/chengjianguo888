### 激光中心线检测软件

一个功能完整的激光条纹中心线检测软件，基于 Python 和 PyQt5 开发。

**主要特性**:
- 🎯 支持三种检测算法（灰度重心法、高斯拟合法、极值法）
- 🖼️ 友好的图形化用户界面
- 📊 实时参数调节和结果可视化
- 💾 数据导出为 CSV 格式
- 🌏 完整的中文界面和文档

**快速开始**:
```bash
cd laser_centerline_detection
pip install -r requirements.txt
python main.py
```

详细信息请查看 [激光中心线检测软件文档](./laser_centerline_detection/README.md)
