# 示例图像目录

本目录用于存放激光条纹示例图像。

## 图像要求

适合本软件处理的激光条纹图像应具有以下特点：

1. **图像格式**: 支持 JPG, PNG, BMP, TIFF 等常见格式
2. **图像质量**: 
   - 清晰度高
   - 噪声较少
   - 对比度适中
3. **激光条纹特征**:
   - 条纹连续
   - 宽度相对均匀
   - 与背景有明显区别

## 测试图像

如需测试软件功能，可以：

1. 使用实际拍摄的激光条纹图像
2. 使用激光位移传感器采集的图像
3. 使用激光三角测量系统的图像

## 图像预处理建议

对于拍摄的原始图像，建议：

- 调整曝光，使激光条纹清晰可见
- 避免过度曝光导致激光中心饱和
- 保持相机稳定，避免图像模糊
- 使用合适的背景，提高对比度

## 示例说明

将您的测试图像放在此目录下，方便快速访问和测试。

建议的图像命名方式：
- `laser_stripe_01.png`
- `laser_centerline_test.jpg`
- `laser_sample_001.bmp`

等等。

---

**提示**: 本软件支持多种激光条纹检测场景，包括结构光、激光位移测量、激光三角测量等应用。
