# 快速入门指南

本指南将帮助您快速开始使用激光中心线检测软件。

## 1. 安装软件

### 步骤 1: 确保已安装 Python

确保您的系统已安装 Python 3.7 或更高版本：

```bash
python --version
# 或
python3 --version
```

### 步骤 2: 安装依赖包

进入项目目录并安装依赖：

```bash
cd laser_centerline_detection
pip install -r requirements.txt
```

如果速度较慢，可以使用国内镜像源：

```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 步骤 3: 验证安装

运行测试脚本验证安装：

```bash
python test_installation.py
```

如果看到 "🎉 所有测试通过！" 说明安装成功。

## 2. 启动软件

在 `laser_centerline_detection` 目录下运行：

```bash
python main.py
```

软件窗口将会打开。

## 3. 基本使用流程

### 第一步：加载图像

1. 点击菜单栏 **"文件"** → **"打开图像"**
2. 或按快捷键 `Ctrl+O`
3. 选择您的激光条纹图像文件

**提示**：您可以先使用 `sample_images/test_laser_stripe.png` 进行测试。

### 第二步：应用预处理（可选）

1. 调整 **"高斯滤波核大小"** 滑块（推荐值：3-7）
   - 值越大，降噪效果越强，但可能使图像模糊
   - 对于噪声较大的图像，使用较大的值
   
2. 点击 **"应用滤波"** 按钮

### 第三步：选择检测算法

在 **"检测算法"** 下拉框中选择：

- **灰度重心法**：适合大多数情况，速度快，精度适中
- **高斯拟合法**：精度最高，但计算较慢（推荐用于精密测量）
- **极值法**：速度最快，适合清晰的激光条纹

### 第四步：检测中心线

点击 **"检测中心线"** 按钮。

检测结果将显示在右侧的 **"检测结果"** 图像区域。

### 第五步：查看和导出结果

- **查看坐标数据**：在右侧表格中查看详细的坐标数据
- **保存结果图像**：
  - 点击 **"文件"** → **"保存结果图像"**
  - 或按 `Ctrl+S`
- **导出坐标数据**：
  - 点击 **"文件"** → **"导出数据"**
  - 或按 `Ctrl+E`
  - 数据将保存为 CSV 格式

## 4. 快速测试

想要快速测试软件？运行以下命令：

```bash
# 确保在 laser_centerline_detection 目录下
python main.py
```

然后：
1. 打开 `sample_images/test_laser_stripe.png`
2. 选择 "灰度重心法"
3. 点击 "检测中心线"

您将看到检测结果！

## 5. 常见使用技巧

### 提高检测精度

1. **调整高斯滤波**：
   - 图像噪声大 → 增大滤波核（7, 9）
   - 图像清晰 → 减小滤波核（3, 5）

2. **选择合适的算法**：
   - 激光条纹清晰 → 极值法（最快）
   - 一般情况 → 灰度重心法（平衡）
   - 需要高精度 → 高斯拟合法（最准确）

3. **图像质量要求**：
   - 激光条纹要连续
   - 与背景有明显对比度
   - 避免过度曝光

### 处理不同类型的激光条纹

- **宽激光条纹**：使用灰度重心法或高斯拟合法
- **窄激光条纹**：使用极值法
- **不均匀的激光条纹**：使用高斯拟合法

## 7. 故障排除

### 问题：无法加载图像
- **解决方案**：确保图像格式正确（支持 jpg, png, bmp, tiff）

### 问题：检测不到中心线
- **解决方案**：
  1. 检查图像中是否有明显的激光条纹
  2. 尝试调整高斯滤波参数
  3. 更换不同的检测算法

### 问题：软件无法启动
- **解决方案**：
  1. 运行 `python test_installation.py` 检查安装
  2. 确保所有依赖包已正确安装

### 问题：检测结果不准确
- **解决方案**：
  1. 使用高斯拟合法提高精度
  2. 调整预处理参数
  3. 确保图像质量良好
